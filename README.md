# 25 games by New Year

https://gevernus.github.io/games/ — a challenge: 25 small web games from October 19 to December 31, 2026, built with AI
agents. Every game is a level down the shaft, and you can play each one right on the site.

This repo is the published build only. The source of the page lives in the challenge's meta repo (`site/`), assembled by
`node site/publish.mjs <out>`.
